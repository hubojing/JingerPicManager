# JingerPicManager

一款给 Windows 电脑用的本地相册管理软件。

把散落在各个文件夹里的照片整理成一个统一的照片库：自动生成网格缩略图、按时间排列、归入相册，还能离线识别照片里的人物。**所有处理都在你自己的电脑上完成，照片不会上传到任何地方。**

> 当前版本 **0.0.1**，仅支持 Windows。

---

## 下载与运行

1. 到 [**Releases 页面**](https://github.com/hubojing/JingerPicManager/releases/latest) 下载最新版本的 `JingerPicManager-v0.0.1-windows-x64.zip`。
2. 解压到任意位置，**双击 `JingerPicManager.exe`** 即可运行。
3. 无需安装，不会往注册表写东西；不想用了直接删掉文件夹就是卸载。

**当前版本**：[v0.0.1](https://github.com/hubojing/JingerPicManager/releases/latest) · **文件大小**：约 50 MB

**系统要求**：Windows 10 或 Windows 11（64 位），约 200 MB 可用空间。

> 如果首次启动被系统提示"未知发布者"，属正常现象 —— 程序尚未做代码签名，选择"仍要运行"即可。

## 三分钟上手

1. **导入照片**：进入「图片库」，点右上角 **导入文件夹**，选中你的照片目录。程序会自动递归扫描并生成缩略图，**不会改动、移动或重命名你的任何原始照片**。
2. **浏览**：缩略图网格按时间倒序排列（最新的在最前），可按月/日的日期分组查看。
3. **看大图**：双击任意缩略图进入全屏查看，照片方向会按拍摄信息自动摆正。
4. **整理相册**：在「相册」里新建相册，把喜欢的照片加进去。一张照片可以同时属于多个相册。
5. **找到同一个人**：进入「人物」，点右上角 **扫描人脸**，稍等片刻即可按人脸自动分组，再给每个人起个名字。

## 主要功能

- **照片库**：全部已导入照片的统一视图，网格缩略图 + 密度可调 + 滚动懒加载，上万张也不卡。
- **相册**：自建相册是照片的**标签**，而不是复制或移动。把照片加入相册、从相册移出，都不会影响磁盘上的原文件。
- **时间线**：支持按拍摄时间正序/倒序、文件名、导入时间排序，并可切换按日期分组。
- **大图查看**：全屏浏览、左右翻阅，并按拍摄信息自动摆正方向。
- **人物识别**：完全离线的人脸检测与聚类（识别过程在你机器上进行，不使用任何云端服务），自动把同一个人的照片聚到一起，支持随时重命名。
- **格式支持**：常见图片（JPG / PNG / GIF / BMP / WebP / TIFF）、手机照片（HEIC / HEIF）、相机 RAW（CR2 / CR3 / ARW / NEF / DNG 等），以及视频文件（MP4 / MOV / AVI / MKV 等）。
- **设置**：可自由指定缩略图缓存放在哪个磁盘（例如换到 SSD 提速）、随时一键清除缓存（清除后可重新导入重建，不影响原照片）。

## 常见问题

**首次导入为什么慢？**
需要读取每张照片并生成缩略图、提取拍摄信息，照片越多耗时越久（界面有进度提示）。之后再次打开是即时的；原照片保持不变。

**我的照片会被修改或上传吗？**
都不会。程序对原文件**只读**，全程离线，不需要登录账号，也没有上传通道。

**缩略图和数据存在哪里？**
在应用数据目录下的 `jingerpicmanager` 文件夹（Windows 上通常是 `%APPDATA%\jingerpicmanager`）。缩略图缓存的具体位置可以在「设置」里改到你想要的位置。

**人物分组不准怎么办？**
识别效果会受照片清晰度、侧脸角度、遮挡和光线影响。发现分错或漏识别时，可以先用「重命名」给自己看到的分组起名，更细的手动合并 / 拆分校正正在开发中。

**支持哪些系统？**
目前只有 Windows。Linux / macOS 版本在计划中。
